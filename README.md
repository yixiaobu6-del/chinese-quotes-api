# 中文金句库API

写文章找不到好金句？
**600+金句帮你提升文案质量。**

[![HTML](https://img.shields.io/badge/打开即用-无需安装-orange)]()

## 金句不再"找不到"

- **金句库**：约600条精选金句
- **来源追踪**：每条金句标注出处
- **场景匹配**：按场景推荐合适金句
- **卡片生成**：Canvas生成精美金句卡片

## 怎么用

打开 `web/index.html` → 搜索/浏览金句 → 生成卡片
